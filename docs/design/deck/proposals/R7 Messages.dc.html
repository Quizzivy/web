Messages, in the states the deck does not draw

The deck draws Messages twice, for a teacher and for a student, with every thread full and every send working. R7 builds both screens (T-R7.20, T-R7.21), and its plan names what the drawing leaves out: a file in a message, the Details popover, a list that is loading, empty or broken, a send that fails, and a thread nobody may write in any more. This page draws those from the deck’s own parts and puts the screens in Vietnamese for the first time. Three things the deck drew change, all on the owner’s word: the Attach dialog attaches and no longer sends, Enter does not send in a class channel, and a Word file can be attached. Two rules of the plan change the same way: a conversation stays open after a class ends, and a teacher can write first to a former student.

A file in a message An attachment is a chip to download, on its sender’s side.
  • The deck writes “Attachment · name” in a bubble. A chip says what the file is before it is opened: its kind, its name, its size, and Download.
  • It follows the sender (DG-91): in the teacher’s bubble on the right, in the announcement’s card for a class, on the left for the student who receives it.
  • PDF, Word, pictures and audio can be attached. Word files were added by the owner; the deck’s dialog names the other three.
  • A file is a download and nothing more. No picture is shown in the thread and no audio plays there, as the server serves every attachment as a download.
When it does not work One sentence and one action, where the trouble is.
  • A list or a thread that cannot load says so in its own pane and offers “Thử lại”. The other pane stays as it was.
  • A send that fails keeps its bubble, with “Chưa gửi được” and “Thử lại” under it. The words are never lost.
  • Leaving a class closes no conversation: a teacher and a student who have one can go on writing (Q5, decided). The composer gives its place to a reason only when the other account is disabled, or a class is archived.
What cannot be taken back Nothing sent can be edited or deleted, so the screen says who will get it.
  • Messages are kept as written, to protect both sides: most students are minors. That is the plan’s decision and this page does not reopen it.
  • A file does not leave with the dialog. It waits in the composer, where the teacher writes a message with it or presses Send as it is (Q3, decided).
  • In a class channel Enter makes a new line and only the button posts, so a slip of a key cannot reach 24 students (Q2, decided). The class composer keeps the deck’s line, “Gửi tới cả 24 học viên”.
