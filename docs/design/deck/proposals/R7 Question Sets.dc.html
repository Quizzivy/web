Question sets in the bank

R7 lets a teacher share questions as a set, and the deck draws no set. This page draws the four places a set shows: the bank, the Add to set dialog, the set's own page for its owner and for a recipient, and the share dialog with the two states the deck leaves out. Every part comes from the deck: the bank's filter aside and bulk bar, the form dialog, Shared with me's access pill and the share dialog. The frames are in Vietnamese first, with English one click away.

{{ c }}
Where does a set live? In the bank's filter aside, as the first group, and on a page of its own.
  • A set is a named list of questions from the owner's bank (DG-90). It is a place to go, so its rows are links and carry no checkbox.
  • Below 1024 the group sits in the Filters sheet, where the aside's other groups already go.
  • The set page is the bank's table with the set's name above it, so a teacher who knows the bank knows the page.
How is a set made and shared? From a selection in the bank. "Share…" names the set first.
  • The bulk bar gains "Add to set": pick one of your sets, or name a new one.
  • "Share…" keeps the place the deck gives it. It asks for a name, creates the set and opens the deck's share dialog on it.
  • The header's "Share" button goes. The deck shared "All my questions" from it, and a set holds at most 500 questions the owner chose.
What does a recipient see? The same page, with the owner, the access pill and one sentence.
  • The pill is Shared with me's: a pencil on the accent tint for Can edit, an eye on the muted tint for Can use.
  • The header's buttons follow the access, so nothing is offered that the server refuses.
  • The "Used" column counts the owner's tests, so a recipient does not see it.

The screens at 1280 and 360

The two frames share one state. Use the bar above to pick the screen, its state, the access, the language and the theme. Inside the frames a set's row opens its page, "Add to set" and "Share…" open their dialog, and the set page's share button opens the share dialog. The shell is drawn plainly so the page stands out: a 248px sidebar from 1024, a drawer below that, and 28 or 14px gutters, as the page-width design sets them. From 768 to 1023 the page is the 360 layout with the table's Type and Level columns back.
